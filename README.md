# Customer-Churn-Analysis
Customer Churn Analysis and Prediction using Python, SQL, Power BI and Machine Learning


# Project Overview

This project analyzes customer churn behavior using the Telco Customer Churn dataset and predicts customer churn using Machine Learning.

# Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Scikit-Learn

# Dataset

The dataset contains customer demographics, contract details, internet services, monthly charges, tenure, and churn status.

# Exploratory Data Analysis

Performed analysis on:

- Customer Churn Distribution
- Contract Type vs Churn
- Internet Service vs Churn
- Monthly Charges Distribution
- Customer Tenure Distribution

# Key Insights

- Customers with month-to-month contracts have the highest churn rate.
- Fiber optic users show higher churn behavior compared to DSL users.
- Customers with higher monthly charges are more likely to churn.
- Customers with shorter tenure tend to leave more frequently.

# Machine Learning Model

Model Used:
- Logistic Regression

Performance:
- Accuracy: 79.9%
